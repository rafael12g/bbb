BLACKWOOD

Institut psychiatrique — Dossier 0049

⚠ Ce jeu contient des scènes pouvant heurter. Jouez au casque, dans le noir, pour l'expérience complète.

Cliquez n'importe où pour activer le son.

Comment jouer

  • Z Q S D / Flèches — Se déplacer
  • Souris — Orienter la lampe torche
  • Maj — Courir (consomme l'endurance)
  • E — Interagir / Ramasser / Ouvrir
  • F — Allumer / éteindre la lampe
  • Espace — Se cacher / sortir d'un casier
  • 1‑6 — Utiliser un objet de la barre
  • I — Inventaire   J — Journal   Tab — Objectifs
  • Échap — Pause

• Dans le noir, votre santé mentale chute. La lumière vous protège mais attire l'Autre.

• Courir et claquer les portes fait du bruit. Le bruit le rapproche.

• Si vous l'entendez tout près, éteignez la lampe et cachez‑vous.

• La partie est sauvegardée automatiquement à chaque chapitre.

À propos

BLACKWOOD est un survival‑horror entièrement jouable dans le navigateur.

Aucune installation, aucune dépendance : moteur, éclairage, IA et audio sont générés en temps réel.

Audio synthétisé via Web Audio API. Rendu Canvas 2D.
